## 重建知识边界与作者的思考路径（重要）

### 前人在哪里撞墙

先看这张论文自己不会明说、但决定了一切的背景图：DNA 语言模型走到 2025 年，tokenization 上其实只有三条路，每条都撞在各自的墙上。

**单核苷酸（byte-level）路线。** Nucleotide Transformer（NT）、Caduceus、HyenaDNA、Evo2、Generator 都直接把碱基当 token。信息零损失，代价是序列极长——人类基因组 32 亿个碱基，单核苷酸建模意味着上下文里每一个碱基都要进注意力。Evo2 的回答是 40B 参数、9.3 万亿碱基对训练数据、1M token 上下文，纯靠算力碾过去。这条路没有问题意识，只有成本问题：大多数组没有这个预算，而 Transformer 注意力对序列长度是平方的。

**固定 k-mer 路线。** DNABERT 和 NT 用 6-mer 划格子。这是三条路里失败最结构性的：k-mer 的边界由全局网格决定，与序列内容完全无关。同一段生物学区域，平移一个碱基，token 序列整体错位——NT 自己的论文报告过这个现象，并且要靠反向互补（RC）和 shift augmentation 去补。补丁打在这种失败上，说明这个失败是结构性的：不管怎么增广，分词函数本身仍然不知道自己在切什么。任何依赖精确 token 一致性的下游场景（变异解读、motif 比对）都会在这种分词下出问题。

**BPE 路线。** DNABERT-2 和 GROVER 把 NLP 的 BPE 搬过来，按语料频率学合并规则。在基因组上，频率最高的是什么？重复元件——SINE/LINE、微卫星、低复杂度区，占人类基因组一半以上。于是 BPE 词表被非功能序列占据，真正有功能的短 motif（10 来 bp 的转录因子结合位点、剪接位点）反而被拆散。BPE 还有第二个问题：合并是贪心的，一个 InDel 会改变其后所有合并决定，token 解析从突变点起整体错位。而且 BPE 的粒度是全局均匀的——它不管局部上下文，启动子里的一个碱基和重复区里的一个碱基在 BPE 眼里权重相同。

这三条路共享一个没人说破的默认假设：**tokenizer 是一个不依赖输入内容的固定函数**。要么固定网格（k-mer），要么固定词表加贪心合并（BPE），要么干脆不分（byte-level）。这个假设在 NLP 里大体成立——词是天然单位，BPE 词表抓的是人类语料的统计结构。搬到 DNA 上它就崩了：DNA 没有天然的"词"，且信息密度在基因组上极不均匀。外显子、启动子、剪接位点上每一个碱基都受约束，重复区几十 kb 全是冗余。一个固定函数不可能同时伺候这两种区域：细了，重复区白付计算；粗了，功能区的碱基级细节被平均掉。

### 直接起点：H-Net

这篇论文的真正起点不是上述任何一条路，而是 2025 年 7 月挂上 arXiv 的 H-Net（Hwang, Wang, Gu，2507.07955）。H-Net 做了一件打破默认假设的事：**把 token 边界变成模型自己的可训练决策**。机制分四块：每一层先过一个序列编码器得到每个位置的上下文表示；一个路由网络（routing network）把每个位置投影成 query 和 key 两个向量，用相邻位置投影的余弦相似度算出边界概率，越不相似越该切；阈值 0.5 定边界，块内平均池化得到块表示；再用一个 ratio loss 把边界总数控制在目标压缩率附近。整个东西端到端可训练，在自回归语言模型和 DNA 任务上匹敌固定 tokenizer。

H-Net 证明了机制可行，这是作者敢于投入的底气之一。但 H-Net 长着自回归的基因：编码器是单向的（自回归只需要看左边），解码端是一个"smoothing module"——插值式地把块表示摊回每个成员位置。自回归模型只需要预测下一个 token，所以 smoothing 够用。

### 两个卡点

DNA 表示学习的主流评测生态——NT benchmark（18 个任务）和 Genomic benchmark（8 个任务）——几乎全是 MLM 模型的地盘。MLM 和自回归对解码端的要求完全不同：每个被 mask 的位置都要在原始分辨率上重建，且要用两侧上下文。H-Net 的两处设计正好卡死在这里：

第一，smoothing module 是插值，给同一块内所有位置复制同一个向量。自回归场景下它只需要"下一个 token 的位置"有一个向量，MLM 场景下每个位置都要预测，插值无法区分块内不同位置的差异，也没有从两侧汇聚信息的机制。这一处不换，移植必死。

第二，mask token 会污染路由网络。mask 嵌入与邻居的表示天然不相似，路由器会学到"有 mask 就切"的边界模式——这是预训练特有的模式，下游微调时没有 mask，学到的分词就失效了。更糟的是 mask 嵌入若被平均进块表示，整个块的表示都被污染。这一处不处理，分词在预训练和下游之间就是两套东西。

我推断作者的路径是这样走的（推断，依据是论文措辞和这两个设计的"补丁"性质）：拿到 H-Net 代码，第一版直接换 MLM 目标跑预训练——结果要么重建质量差（smoothing 的锅），要么路由网络退化出 mask 特异的边界。于是动手三处：编码器换成双向的 Caduceus（BiMamba，RC 等变，线性复杂度，能看两侧）；smoothing 换成 cross-attention 上采样——细粒度位置做 query、粗表示做 key/value，每个位置自己"问"内容在哪；mask 位置前后强制边界，让 mask 永远是 singleton 块。再加一个 U-Net 式残差，把编码器的碱基级细节直连到解码端。这三处手术的性质是"问题逼出来的修复"，不是先验设计——论文自己也承认这两处是"architectural improvements over the vanilla H-Net"，并专门做了 H-Net 对比实验（Figure 2）来证明它们必要。

### 底牌与目标会议

一篇论文投出去，作者手里一定有一张底牌。这篇的底牌不是某一处技术，而是"**低风险移植 + 一个必然出现的漂亮现象**"。移植风险低，因为 H-Net 三个月前刚证明机制可行且代码公开；漂亮现象是：MLM 损失天然惩罚"把信息量不同的相邻碱基平均掉"——所以边界必然向信息密集区聚集，学出来的分词会和功能注释对得上。Figure 1b（突变鲁棒性）和 1c（块大小分布）放在第一页，作者显然知道这是最让审稿人信服的证据：一张图说"分词稳"，一张图说"分词懂生物学"。

目标会议按 OpenReview 时间线推断是 ICLR 2026。投 ICLR 的证据配置是：两个标准基准的大表（NT + Genomic）+ 效率叙事（156M 对 1.2B）+ 一个可解释的 emergent 现象（分词复现功能注释）。这是典型打法，效率叙事专门写给 ML 审稿人，生物学分析专门写给怀疑"可学习分词只是噱头"的人。

措辞强度分布也符合这个判断。贡献列表写 "State-of-the-art performance"，但 Genomic benchmark 上其实只是平均 rank 第一、平均 accuracy 第二，"outperforms" 是溢美。方法部分全是 "we adopt / we implement / we employ"——工程口吻，诚实。分析部分 "we observe / reveals"——观察口吻。全文没有 "we prove"。最心虚的地方是剪接位点三个任务全输给 Generator（0.965 对 0.979），正文一句没提，只说 "gains are especially more pronounced upon histone mark prediction tasks"——选择性汇报，后面实验部分细说。

### 四个核心问题

**Problem。** 在 DNA 语言模型里，如何让 tokenization 成为一个随输入内容自适应、端到端可训练的机制：把表示分辨率（等价于计算预算）分配到信息密集的功能区域，压缩冗余的重复区域，并且在双向 MLM 框架下保持碱基级重建能力。知识边界的缺口是具体的：动态可学习 tokenization 此前只存在于自回归模型（H-Net），双向 MLM 版本需要解决两个新问题——mask 位置的双侧上下文重建（smoothing 做不到），以及 mask token 对路由网络的污染。

**Motivation。** 三层。实践层：tokenization 控制的是"计算换分辨率"的兑换率。一个把分辨率花在功能区、把重复区压掉的分词器，能让 156M 的模型在基准上打过 1.2B 的模型——这是论文自己展示的价值。科学层：如果无监督 MLM 学出来的 segmentation 复现启动子、外显子、重复元件的注释，这就是"预测压力编码功能结构"的直接证据，回答"基因组的 grammar 到底存不存在、在哪一层"这个问题。能力层：对突变鲁棒的分词是变异解读类应用的前提——临床上核心问题是"这个突变改变了什么"，如果单个 InDel 就让模型的分词整体错位，模型对这个突变的表示就是不可信的。

**State of Research / Gap。** 这项工作之前：k-mer（DNABERT、NT）结构性地对 phase shift 敏感，NT 靠增广打补丁；BPE（DNABERT-2、GROVER）按频率学合并，词表被重复元件占据，粒度全局均匀、与局部功能无关，且贪心合并对 InDel 脆弱；byte-level（HyenaDNA、Evo2、Generator）保真但成本高，Evo2 用 40B 参数硬扛；Caduceus 提供了线性复杂度的双向 SSM 主干。可学习 tokenization 在非自回归模型里只有 Charformer 的软池化（梯度加权池化，无硬边界），在 NLP 里没有流行起来；H-Net 把硬边界动态 chunking 做进了自回归模型。缺口为什么之前没人补：机制本身（H-Net）2025 年 7 月才出现，且它的解码设计锁死在自回归场景；此前 DNA 社区把 tokenization 当作预处理，没有人把它当作模型的可训练部分去重新设计。真正的技术瓶颈是两处：单向插值式上采样无法在 MLM 里重建 masked 位置；mask token 与分块机制的直接冲突。

**Contribution。** 核心洞见一句话：**把 token 边界当作模型的一个可训练决策，用任务损失去训练它——边界自然落在"合并会伤害预测"的位置，于是 tokenizer 变成基因组的自监督信息密度图。** 理解了这个，其余一切都顺理成章：为什么边界对齐功能注释、为什么对突变鲁棒（边界是内容的平滑函数而非内容的函数）、为什么小的模型能赢（分辨率分配比分辨率总量重要）。

归纳贡献，不按论文的叙事顺序：
1. **新解决方案**：把 H-Net 的动态 chunking 移植到双向 DNA MLM。关键手术是 cross-attention dechunking（细粒度位置做 query 的"内容路由"）+ U-Net 式残差 + mask 强制边界 + 特殊 token 直通。新意不在机制本身，在于让它第一次在双向 MLM 下工作。
2. **新理解**：无监督 MLM 学出的 segmentation 复现功能注释（启动子/外显子小块、重复区大块，大块可达 320bp），并且比 BPE 更抗 InDel。这推进的是"基因组的信息密度结构可以被预测目标本身发现"这条知识边界。
3. **新基准结果**：156M 参数、只训人类基因组，NT benchmark 平均 MCC 0.772 超过 1.2B 的 Generator（0.728），平均 rank 1.67；Genomic benchmark 平均 rank 第一。

## 1. Abstract｜全篇压缩

### 1.1 Task

DNA 语言模型的任务是把基因组序列编码成可用表示，支撑下游的功能预测（组蛋白修饰、启动子/增强子、剪接位点）。本文处理的是这个任务的前置环节：**分词**——把碱基序列解析成更短的块序列。关键指标是 NT benchmark 的 MCC 和 Genomic benchmark 的 accuracy，以及分词本身的鲁棒性。

### 1.2 Technical challenge

固定分词（k-mer、BPE）是输入内容的盲函数：k-mer 对 shift/突变结构性敏感，BPE 按频率切、粒度全局均匀。而 DNA 的信息密度极不均匀——功能区每个碱基都重要，重复区整段冗余。在双向 MLM 框架下引入可学习动态分词，还要解决两个此前没人解决的问题：mask 位置的双侧重建，mask token 对分词学习的污染。

### 1.3 Key insight

让边界成为模型的可训练决策，用任务损失塑造它：边界自动落在"合并会伤害预测"的位置。分词从固定的预处理函数变成基因组的自监督信息密度图。收益：分辨率（= 计算）自动流向功能区；分词是内容的平滑函数，天然抗突变。

### 1.4 Technical contributions

- **动态 chunking 移植到双向 MLM**：两阶段 Caduceus（BiMamba）编码器 + 余弦相似度路由网络切块；主网络是 8 层 RoPE Transformer，在压缩后的块序列上建模长程依赖；cross-attention 两阶段上采样 + 残差恢复碱基分辨率。解决了"压缩后还要逐碱基预测"的矛盾。
- **mask 保护机制**：mask 位置前后强制边界，mask 永远自成一块，防止路由器学到 mask 特有的边界模式。解决了预训练与下游的分词分布不一致问题。
- **基准表现**：NT benchmark 上 156M 参数打平并超过 1.2B 的 Generator；组蛋白任务平均相对提升 14.2%。
- **分词行为分析**：学出的分词复现功能注释（启动子/外显子小块、重复区大块），对 InDel 的鲁棒性显著高于 BPE。

### 1.5 Experiment

预训练用 HG38 人类参考基因组（Enformer 划分，约 350 亿碱基对）。NT benchmark：10 折交叉验证，总平均 MCC 0.772（Generator 0.728，此前最好），平均 rank 1.67；18 个任务中 12 个严格最好、1 个并列（正文声称 10 个，对不上，见 4.2）。Genomic benchmark：平均 accuracy 0.879 第二、平均 rank 2.19 第一（Generator 0.887 / 2.50）。消融：对 H-Net 全胜，剪接位点增益最大。分析：块大小与功能注释对齐；ClinVar 上 InDel 分词相似度 0.85 vs BPE 0.75。

## 2. Introduction

### 2.1 Task and application

- 任务定义：输入是原始 DNA 碱基序列（预训练最长 8192 bp，论文正文另一处写 2048，见 3.6 的不一致清单），输出是每个碱基的 4 类分布（MLM 目标）；下游任务是功能预测——组蛋白修饰（输入 500bp 窗口，预测该位点是否有某个组蛋白标记）、调控注释（启动子/增强子分类）、剪接位点注释。预训练任务本身是"预测被 mask 的碱基"。
- 重要性：基因组序列注释是功能基因组学的基础设施。人类基因组里绝大部分非编码区的功能仍然未知；靠实验测定（ChIP-seq、CAGE）昂贵且覆盖有限，序列模型是当前最有希望的大规模注释工具。而分词决定模型的成本结构和它能看到的尺度。
- 应用：论文自己没演示生成或设计应用，只做下游功能预测基准。这与 Evo/Evo2（设计 CRISPR 复合物、噬菌体）形成对照——本文是纯表示学习定位。

### 2.2 Technical challenges for previous methods｜本文真正要解决的问题

#### Technical challenge 1 — 固定分词与生物上下文失配

**Previous method：** k-mer 划固定网格（DNABERT、NT 用 6-mer）；BPE 按语料频率学合并规则（DNABERT-2、GROVER）。

**Failure cases / limitation：** k-mer：同一段序列平移一个碱基，token 序列整体错位——NT 论文自己报告了这一点。BPE：一个 InDel 改变其后所有贪心合并决定；且词表被重复元件占据，功能性短 motif 被拆散；粒度全局均匀，功能区与重复区同等对待。

**Technical reason：** 两者的边界都是序列字符串的固定函数，不感知"这个碱基在生物学上重不重要"。k-mer 的失败是结构性的——网格与内容无关，任何增广都是补丁。BPE 的失败来自两个机制：频率优先（基因组里最高频的是重复元件）和贪心合并的连锁反应（一个局部变化导致全局解析错位）。

**Research gap：** 需要一种分词：边界是局部上下文内容的函数，粒度随信息密度自适应。这就是本文的 Problem。

#### Technical challenge 2 — 动态 chunking 在 MLM 下的两个障碍

**Previous method：** H-Net 的动态 chunking（自回归模型）：编码器单向，解码端 smoothing module 插值上采样。

**Failure cases / limitation：** 直接换 MLM 目标后：smoothing 给同一块内所有位置复制同一个向量，块内不同位置的碱基预测无从区分；mask 位置的重建需要双侧上下文，插值提供不了。同时 mask 嵌入与邻居不相似，路由器学会"有 mask 就切"。

**Technical reason：** smoothing 是无内容的插值，没有"哪个位置该拿到哪部分信息"的路由机制；单向编码器看不到右侧上下文。mask 问题来自机制耦合：分块由表示相似度决定，而 mask 的表示天然离群。

**Research gap：** 双向上下文编码 + 内容感知的上采样 + mask 与分块的解耦。这是本文的工程增量，也是"之前为什么没人做"的答案——机制（H-Net）2025 年 7 月才出现，且这两个障碍不解决，移植必死。

### 2.3 Our pipeline：如何解决 challenge

#### 2.3.1 核心解题思路

边界是模型的输出而非数据的函数。两阶段层次 chunking 压缩（Caduceus 编码 + 余弦路由 + 池化 + ratio loss 控压缩率）→ 压缩序列过重型 Transformer → cross-attention 两阶段上采样 + 残差 → 碱基分辨率解码。分词、主网络、解码全部端到端，由 MLM 损失统一塑造。

#### 2.3.2 贡献一：动态 chunking 移植到双向 MLM

**Problem addressed：** challenge 2——mask 位置的双侧重建。

**Approach：** 编码器换成双向 Caduceus；smoothing 换成 cross-attention 上采样（细粒度编码器输出做 query，粗表示做 key/value）；z^(2) 与 x̂^(0) 残差相加保住碱基级细节；mask 强制边界 + 特殊 token 直通主网络。

**Advantage：** 每个细粒度位置用自己的 query 从压缩表示里"检索"内容，块内位置不再共享同一个向量；残差保证即使上采样有损，碱基级细节还在。验证：对 H-Net 的消融全胜，剪接位点（对碱基级细节最敏感的任务族）增益最大。

#### 2.3.3 贡献二：生物学对齐的分词与基准表现

**Problem addressed：** challenge 1——分词与生物上下文失配。

## 3. Method

### 3.1 Overview

#### 具体的任务

- 输入：DNA 碱基序列 x = (x_1, …, x_T)，x_t ∈ {A, C, G, T, N, 特殊 token}，词表 16；预训练 T 最长 8192（正文 3.2 写 2048，两处矛盾，见 3.6）。
- 输出：每个被 mask 位置 t 的碱基分布（4 类 + 特殊类，CE 损失只打在 mask 位置，重复区权重 0.1）。
- 目标：预训练学表示；下游去掉 LM head，池化后过线性层分类。

#### 方法总体流程

编码（两阶段 chunking）→ 主网络（压缩域 Transformer）→ 解码（两阶段 dechunking + 残差 + 最终 Caduceus）→ LM head。信息流：x^(0)（T×d）→ Caduceus → x̂^(0)（T×d）→ 路由切块池化 → x^(1)（T′×d）→ Caduceus → x̂^(1) → 路由切块池化 → x^(2)（T″×d）→ 8 层 Transformer → z^(0)（T″×d）→ cross-attention 上采样（Q 来自 x^(1)）→ z^(1)（T′×d）→ cross-attention 上采样（Q 来自 x̂^(0)，论文未明说，见下）→ z^(2)（T×d）→ +x̂^(0) 残差 → 2 层 Caduceus → logits（T×16）。

符号表（全部一次列清）：

| 符号 | 形状 | 含义 |
| ---- | ---- | ---- |
| x^(0) | T × d | 碱基嵌入，d = 1024 |
| x̂^(0) | T × d | stage-1 编码器（2 层 BiMamba）输出，未切块 |
| q_t, k_t | d 维 | 路由网络对位置 t 的 query/key 投影（W_q, W_k ∈ R^{d×d}） |
| p_t^(s) | 标量 ∈ [0,1] | 位置 t 处（阶段 s 输入分辨率）的边界概率 |
| b_t^(s) | 0/1 | 边界指示，b_t = 1(p_t ≥ 0.5)；b_1 ≡ 1（首位永远开块，论文的 T′ = Σb_t 隐含此约定） |
| x^(1) | T′ × d | stage-1 切块池化后的块嵌入，T′ = 块数 |
| x^(2) | T″ × d | stage-2 切块池化后的块嵌入，T″ < T′ |
| z^(0) | T″ × d | 主网络（8 层 Transformer）输出 |
| z^(1) | T′ × d | 第一级上采样输出 |
| z^(2) | T × d | 第二级上采样输出 |
| α^(s) | 标量 | 阶段 s 的目标压缩率（**全文未给数值**） |
| λ | 标量 | ratio loss 权重（**全文未给数值**） |
| W_enc,q^(s), W_enc,k^(s) | d × d | 编码器路由网络参数，s ∈ {1,2} |
| W_dec,q^(s), W_dec,k^(s), W_dec,v^(s), W_dec,o^(s) | d × d | 解码器 cross-attention 上采样参数 |

参数账（Table 5）：stage-1 编码器 14M + 路由 2M + stage-2 编码器 14M + 路由 2M + 主网络 100M + 解码器 14M + 上采样器 4M×2 + 残差投影 1M = 155M，加上词嵌入和 LM head（各约 16k）≈ 156M。主网络占 64%。"轻量"的编码解码器合计 51M，其实占三分之一——轻量是相对 1.2B 基线说的，不是相对自己的主网络。

两处细节论文没说清，先说明我的读法：块表示怎么来的——论文只写"downsampling the embeddings according to these boundaries"，H-Net 的做法是块内平均池化，我按此理解（推断）。stage-2 上采样的 query 来源——论文只说"same process is applied"，按对称性应是 x̂^(0)（碱基分辨率的编码器输出），因为残差项用的就是 x̂^(0)（推断）。

### 3.2 Pipeline module 1 — 路由网络：边界概率

**Motivation：** 切块的第一步是回答"这个位置该不该是块的起点"。判断标准不应该是频率（BPE）或网格（k-mer），而应该是内容：**相邻两个位置的内容如果可互换，合并无损失；如果各自携带不同信息，合并就是破坏**。

**做法：** 位置 t 的边界概率（公式 1）：

p_t^(0) = ½ (1 − (q_t^(0))^⊤ k_{t−1}^(0) / (‖q_t^(0)‖·‖k_{t−1}^(0)‖))，其中 q_t = W_enc,q x̂_t，k_t = W_enc,k x̂_t

符号上有一个绕的地方先说破：上标 (0) 表示这个概率作用在第 0 层分辨率（碱基层）上、产出 x^(1)；而 W 的上标 (1) 表示这是第 1 个路由模块。p^(0) 和 W^(1) 属于同一个模块。论文在公式里混用两种标号方式，读的时候按"p 的上标 = 输入分辨率层，W 的上标 = 模块编号"理解。

逐项读这个公式。q_t 和 k_{t−1} 是相邻两个位置各自的两个投影——query 是"我作为块的右边界需要什么"，key 是"我的左邻居能提供什么"。余弦相似度落在 [−1, 1]：同方向 = 内容可互换，正交或反向 = 内容不同。½(1−cos) 把它翻转到 [0,1] 的概率刻度，阈值 0.5 恰好对应 cos = 0。**所以边界判据是：相邻位置的投影夹角超过 90 度才切。** 这个阈值全文固定，压缩率不靠动阈值调节，而是靠 ratio loss 塑造 p 的整体分布（下一节）。

几何读法：把 q_t 看成"位置 t 的内容指向的方向"。相邻位置方向一致，p ≈ 0，不切；方向转了个大弯，p 高，切。一段低复杂度重复序列里所有位置的表示几乎相同，整段合一个块；一段 motif 里每个碱基各指各的方向，每个位置都是边界，块退化为单碱基——这正是"功能区高分辨率"的机制来源。

**为什么能 work：** 边界是编码器输出的函数，而编码器输出是上下文函数。同一个碱基 C 出现在启动子和出现在微卫星里，x̂_t 完全不同，边界决策随之不同。这回答了"为什么不像 BPE 那样也学一个规则"——BPE 学的是与上下文无关的字符串规则，这里学的是上下文条件化决策。

**Technical advantage：** 两个。一是自适应性（粒度随内容变），二是鲁棒性——一个小突变只局部扰动表示，边界的变动也只在局部，不像 BPE 的贪心合并那样连锁反应（定量见 4.6）。代价是要多一个路由网络的参数和训练信号（ratio loss）。

### 3.3 Pipeline module 2 — 切块、两阶段层次压缩与 ratio loss

**做法：** b_t = 1(p_t ≥ 0.5)，块内平均池化（推断自 H-Net）得 x^(1)，再同构地过 stage-2 得到 x^(2)。

**为什么两阶段：** 基因组的结构本身是层次的——motif（10 来 bp）组成结构域（几百 bp），结构域组成大区间。一阶段切块只能在一个尺度上压缩；两阶段让第二层有机会把"相邻的低信息块"（比如两种不同的重复元件相邻）再合并成更大的块，把压缩推向更粗尺度，同时保留第一层的细粒度。Figure 4 里 stage-1 和 stage-2 的块大小分布是两套分布，说明两层确实在不同尺度上工作。

**ratio loss（公式 4）——这是全文最容易误读的公式，慢下来讲。** 路由网络被 0.5 阈值截断后，b̄（边界比例）是不可微的，没法直接要求"边界率等于目标压缩率 α"。H-Net 的解法是一个反馈回路：

L_ratio^(s) = b̄^(s)·p̄^(s)/α^(s) + (1−b̄^(s))·(1−p̄^(s))/(1−α^(s))

其中 b̄ 是边界占比（不可微，梯度不回传），p̄ 是平均边界概率（可微）。把 b̄ 当常数对 p̄ 求导：

dL/dp̄ = b̄/α − (1−b̄)/(1−α)

这个导数说了一件漂亮的事：**它的零点在 b̄ = α。** 边界太多（b̄ > α）时导数为正——损失随 p̄ 增大而增，梯度下降压低 p̄，越过 0.5 阈值的位置变少，b̄ 回落；边界太少（b̄ < α）时导数为负，抬高 p̄，b̄ 回升。数值验证：α = 0.25 时，b̄ = 0.4 → dL/dp̄ = 0.4/0.25 − 0.6/0.75 = 1.6 − 0.8 = +0.8（压）；b̄ = 0.1 → 0.4 − 1.2 = −0.8（抬）；b̄ = 0.25 → 0（平衡）。

注意这个"损失"并不在平衡点取最小——把 b̄ = α 代回去，L = p̄ + (1−p̄) = 1，与 p̄ 无关。它不是一个被最小化的目标，是一个**反馈控制器**：梯度方向告诉路由网络"边界太多还是太少"，值本身没有意义。想通了这一点，就不会纠结"为什么优化到 1 就不动了"。

**mask 保护机制。** 预训练时 15% 的位置被 mask。两个耦合问题：mask 嵌入与邻居不相似，路由器会学到 mask 特异边界；mask 嵌入若被池化进块，块表示被污染。解法暴力但有效：**mask 位置前后强制 b = 1**，mask 永远是单碱基块——它不进任何池化，路由网络也没机会把"附近有 mask"学成切块信号。论文给的动机是"防止模型学到不会泛化到下游的 mask 特异分词"，我推断真实动机来自训练时观察到的路由退化（推断）。代价：预训练时 15% 的位置失去合并自由度，块结构在 mask 附近被拉碎——这是局部吃亏、整体划算的交换。

**特殊 token 直通。** [MASK]、[PAD] 等特殊 token 不进切块流程，直接插入主网络输入。理由同 mask 保护：特殊 token 不是基因组内容，不该影响路由决策，也不该被池化。

**为什么能 work / Technical advantage：** 整体效果是"压缩率全局可控（ratio loss 管总量），边界位置局部最优（MLM 损失管分布）"——两个损失各管一半，这正是这个模块的承重设计。去掉 ratio loss，压缩率漂移，主网络的序列长度不可控；去掉 MLM 压力，路由网络没有关于"哪里该切"的信号。

### 3.4 Pipeline module 3 — 主网络：8 层 RoPE Transformer

**Motivation：** 压缩后的块序列（长度 T″）是"语义层"，适合用注意力做长程交互——此时平方成本负担得起；而碱基层的长序列已经由 BiMamba（线性成本）消化过了。

**做法：** 8 层标准 Transformer：Pre-LN、8 头（每头 128 维，共 1024）、Q/K 上 RMSNorm、MLP 1024→4096→1024（GELU）、RoPE 位置编码。RoPE 施加在**块索引**上（论文未明说，但从结构上只能是块索引）——也就是说主网络的位置感知粒度是块，不是碱基对。这带来一个隐含性质：块边界左右移动几个碱基，块索引序列不变，主网络的输入结构稳定——与鲁棒性叙事一致。

**为什么能 work：** 主网络承接了全模型 64% 的参数和几乎全部注意力算力，但它处理的是压缩序列。T = 8192 时，若两阶段各压 4 倍，T″ = 512，注意力成本降为原来的 (512/8192)² ≈ 1/256。这就是"小模型打大模型"的计算学基础——不过实际压缩率取决于未公开的 α 值，论文没有任何 FLOPs 或墙钟时间测量，"高效"目前只是参数计数和结构论证（见 5.2）。

**Technical advantage：** 用 BiMamba 做编码、Transformer 做主干的混合，本质是按成本结构分工：长序列的低层加工交给线性模型，平方成本的注意力只花在压缩域上。

### 3.5 Pipeline module 4 — cross-attention dechunking 与残差

**Motivation：** 压缩域处理完，要回到碱基分辨率做逐碱基预测。H-Net 的 smoothing 是插值——同一块内所有位置拿到同一个向量，块内差异无从谈起。MLM 要求每个位置都被区分开，尤其 masked 位置要能从两侧上下文重建。所以上采样必须是有内容的：每个细粒度位置应该"问"压缩表示里哪些内容属于自己。

**做法（公式 2）：**

z^(1) = softmax(Q^(1) K^(1)^⊤/√d) V^(1)，其中 Q^(1) = x^(1) W_dec,q，K^(1) = z^(0) W_dec,k，V^(1) = z^(0) W_dec,v

注意 query 来自**编码器的细粒度输出** x^(1)，key/value 来自**主网络的粗输出** z^(0)。输出行数 = query 数 = T′。第二级同构，升到 T。

几何读法：这是一次"内容路由"。细粒度位置（query）带着自己的身份提问"哪个粗块的内容和我有关"，注意力权重就是路由结果，输出是该位置专属的内容组合。同一块内两个位置问法不同，拿到的内容不同——smoothing 做不到的区分度在这里出现了。论文说这设计受 U-Net 启发：编码器各尺度的特征在解码路径被复用，上采样不是无中生有，而是有细粒度锚点的重新组装。

小数值演示（d = 4 示意，实际 d = 1024）：两个细位置 A（在 motif 里）和 C（在重复尾巴里），两个粗块 v_motif = [2,0,0,0]、v_tail = [0,0,1,0]。投影后 q̃_A = [1,0,0,0]，q̃_C = [0,0,1/√2,−1/√2]，k̃_motif = [1,0,0,0]，k̃_tail = [0,0,1/√2,−1/√2]。分数矩阵 QK^⊤/√4 = [[0.5, 0], [0, 0.5]]，softmax 得 [[0.622, 0.378], [0.378, 0.622]]。于是 z_A = 0.622·v_motif + 0.378·v_tail = [1.244, 0, 0.378, 0]，z_C = [0.756, 0, 0.622, 0]。A 位置主要拿到 motif 内容，C 位置主要拿到尾巴内容。**每个位置用同一个压缩表示，组装出不同的东西**——这就是 dechunking 的全部要点。

之后 z^(2) 与 x̂^(0) 残差相加，再过 2 层 BiMamba 得 logits。残差保住碱基级细节——剪接位点这种靠几个碱基的精确序列判别任务（GT-AG 双核苷酸）就靠这条通路；消融中剪接任务对 H-Net 增益最大（Figure 2），与这个机制一致。

**为什么能 work / Technical advantage：** 内容路由 + 残差直连，解决了"压缩无损地回到全分辨率"这个压缩架构的老问题。代价是两级 cross-attention 各 4M 参数，以及每个细位置都要参与 softmax 的算力——上采样本身不便宜，但它是线性的（每位置对每粗块，T′×T″），不改变量级。

### 3.6 预训练

数据：HG38，Enformer 划分（染色体分 2^20 = 1,048,576 bp 的不重叠区段，train/val/test 按区段隔离，防同源泄漏），训练区段 34,021 个，总约 350 亿碱基对。恒定 token 预算每批 2^20 个 token，按序列长度调 batch size。Adam（β1 = 0.95，β2 = 0.9，LR 5×10⁻⁴，cosine）。mask：15% 位置，其中 80% 换 [MASK]、10% 换随机碱基、10% 保留，BERT 式。损失 = MLM CE（重复区权重 0.1，识别重复区的方法论文没说，Evo2 用的是 RepeatMasker 注释，推断）+ λ·L_ratio^(0) + λ·L_ratio^(1)。'N' 映射为 [PAD]，不进损失。

不一致清单（原文问题，非解读）：(1) 正文 3.2 说输入最长 2048 bp，附录 A 表 4 说 8192（2^13）——后者应是准的，因为表 4 是专门给预训练的超参数表；(2) 附录 A 举例"序列长 131k → batch 8"，但最长序列 8192 时 131k 的序列根本不存在——这个例子像是从 H-Net 论文的 token 预算描述里原样搬来的（推断）；(3) β2 = 0.9 偏离惯例（通常 0.95–0.999），可能是 H-Net 设置的继承或笔误；(4) λ 和两个 α 值全文没有——这是复现上最伤的一处；(5) 正文说下游微调用 average pooling，附录 C.1 说 attention pooling。

### 3.7 一个完整的小例子：从输入到输出，加上突变对照

把机制在一段 12 bp 的示意序列上走完（d = 4，数字是构造的，只为看机制；真实模型 d = 1024）。

序列：A C G T C C C A A A T G，位置 1–12。假设 1–4 是一个 motif（转录因子结合位点），5–12 是低复杂度尾巴（CCC + AAA + TG）。

**Stage 1。** 编码器输出 x̂^(0)，路由投影取恒等（示意），各位置的方向：q_1 = [1,0,0,0]，q_2 = [0,1,0,0]，q_3 = [0,0,1,0]，q_4 = [0,0,0,1]——motif 内相邻位置方向正交，每个碱基各指各的；q_5 = … = q_12 = h = [0,0,1/√2,−1/√2]——尾巴里所有位置指向同一个方向。

边界概率 p_t = ½(1−cos(q_t, q_{t−1}))：
- t = 2,3,4：cos = 0 → p = 0.5 → b = 1（三个边界，motif 每个碱基自成一块）
- t = 5：cos(h, q_4) = −1/√2 ≈ −0.707 → p = ½(1+0.707) = 0.85 → b = 1（motif 与尾巴交界，切）
- t = 6…12：cos = 1 → p = 0 → 不切

块：{1},{2},{3},{4},{5–12}，T′ = 5。**motif 四个碱基全部以原表示保留（高分辨率），8 bp 的冗余尾巴压成一个块（压缩）。** 论文 Figure 1c 的机制就是这个，只是真实规模下重复区单块可达 320 bp。

**Stage 2。** 5 个块再过编码器和路由。示意：motif 各块两两不相似、与尾巴块也不相似 → 无新边界，T″ = 5。stage-2 的压缩发生在另一种场合——相邻的低信息块彼此相似时（比如两种重复元件相邻，其 stage-2 表示都被编码器拉到"低复杂度"方向附近），边界消掉，两块并一块。两阶段的差别就在这里：stage 1 在碱基尺度上压，stage 2 在块尺度上把"同类的相邻垃圾"再并一次。

**主网络。** 12 bp → 5 个块 token，8 层 Transformer 在块索引 1–5 上做注意力。

**Dechunking。** 用 3.5 的数值演示：细位置 A 和 C 各自检索到自己的内容；两级上采样升回 12 个位置；加 x̂^(0) 残差；最终 Caduceus 输出 12×4 的 logits。

**Mask 预测。** 设位置 6 的 C 被 mask。保护机制强制 b_6 = b_7 = 1，块变成 {1},{2},{3},{4},{5},{6},{7–12}——mask 是 singleton，其嵌入原样进主网络，两侧上下文（motif 侧和尾巴侧）经主网络和内容路由汇到位置 6，解码器输出 4 类分布。关键对比：没有保护机制时，mask 嵌入会被平均进 {5–12} 的块表示，块被污染，且路由器会记住"mask 旁边要切"。

**突变对照——为什么固定分词在这里输。** 同一序列，三种 tokenizer 面对"位置 6 后插入一个 G"：

- k = 3 的 k-mer：参考 = ACG|TCC|CAA|ATG；插入后 = ACG|TCC|GCA|AAT|G。**插入点之后所有 token 全变**（CAA→GCA，ATG→AAT），模型看到的嵌入序列从第 3 个 token 起完全不同，而生物学功能一点没变。这就是结构性失败。
- BPE（示意词表含合并 AC、GT、CC、AA、TG）：参考 = ac|gt|cc|C|aa|tg；插入后 = ac|gt|cc|G|C|aa|tg。前 3 个 token 相同，之后解析全部改变。真实规模下 Table 3 显示 BPE 对 InDel 的分词相似度掉到 0.75。
- DNAChunker：表示是上下文函数，在低复杂度区插入一个碱基几乎不改变局部表示方向，边界决策只在插入点附近微调，其余不动。Table 3：相似度 0.85。

对比落在具体状态量上：k-mer 的边界是全局网格函数，一处插入全局错位；BPE 的边界是贪心合并的连锁反应；DNAChunker 的边界是局部表示的平滑函数。

## 4. Experiments

### 4.1 实验协议

共用设置：预训练只用 HG38 人类参考基因组（Enformer 划分）。NT benchmark：18 个任务、三类（10 个组蛋白标记、5 个调控注释、3 个剪接位点），10 折交叉验证，指标 MCC，基线分数取自 Wu et al. 2025（Generator 论文）；DNAChunker 每任务网格搜 LR/BS，验证折选 checkpoint。Genomic benchmark：8 个二分类任务（窗口约 200–2000 bp），5 折，指标 accuracy，基线取自 Schiff et al. 2024（Caduceus 论文）；因为 Wu et al. 的划分与 Schiff 不同，作者**自己重跑了 Generator**在 Schiff 划分上的结果（这是对的做法）。所有实验单卡 A100 40GB。

### 4.2 Comparison experiments

#### E1 — Nucleotide Transformer benchmark

- 检验主张：贡献 2/3——156M 模型在 NT benchmark 上超过 1.2B 的 Generator。
- 设置与对照：10 折 CV、MCC、10 个模型对比（Enformer 252M、DNABERT-2 117M、HyenaDNA 55M、NT-multi 2.5B、NT-v2 500M、Caduceus-Ph/PS 8M、GROVER 87M、Generator 1.2B、DNAChunker 156M）。
- 关键结果：总平均 MCC 0.772，对 Generator 0.728（差 +0.044），总平均 rank 1.67 对 2.06。分族：组蛋白 0.701 对 0.625（+12.2% 相对，正文的"+14.2%"是 10 个组蛋白任务逐任务相对提升的**平均**，不是总量的相对提升——两个口径都成立，但正文没说是哪个口径）；调控注释 0.796 对 0.786；剪接 0.965 对 0.979（**输**）。
- 定性现象：赢的 12 个任务集中在组蛋白（9/10，唯一输的是 H4，0.812 对 0.815）和调控注释（Enhancer Type +0.044、Promoter All +0.006、Promoter TATA +0.017）；输的全是剪接（Acceptor −0.013、All −0.010、Donor −0.018）和 Enhancer（−0.024）。
- 能支持的结论：在组蛋白和调控注释类任务上，156M 的 DNAChunker 全面超过此前最好的 1.2B 模型；总体平均 MCC 和平均 rank 第一。
- 不能支持 / 混杂因素：**正文"state-of-the-art performance on 10 out of 18 datasets"与表 1 对不上**——逐行核对，严格最好的有 12 个（9 组蛋白 + Enhancer Type + Promoter All + Promoter TATA），另有 1 个并列（Promoter NonTATA，0.969 对 NT-multi 的 0.969），5 个不是最好。"10/18"的口径论文没说清（可能只算显著领先，或投稿过程中的残留数字）。贡献列表写"outperforms the baselines in the Nucleotide Transformer and Genomic benchmarks"——Genomic benchmark 上平均 accuracy 是第二，这个"outperforms"过界了。剪接三连输正文零提及。

#### E2 — Genomic benchmark

- 检验主张：跨任务族的稳定性。
- 设置与对照：Schiff 划分、5 折、accuracy；Generator 由作者重跑；7 个模型对比（含 264k–470k 参数的小基线）。
- 关键结果：平均 accuracy 0.879（第二，Generator 0.887），平均 rank 2.19（**第一**，Generator 2.50）。赢得两场：Human NonTATA Promoters 0.957 对 0.925（+0.032）、Human Enhancer Ensembl 0.906 对 0.877（+0.029）。输得明显的是：Human Regulatory 0.880 对 0.930（−0.050）、Coding vs Intergenomic 0.926 对 0.960（−0.034）、Human vs Worm 0.969 对 0.979、Mouse Enhancers 0.833 对 0.853。
- 定性现象：Generator 的排名波动大——在 NonTATA Promoters 上排第 6、OCR 和 Ensembl 上排第 4，与其在多数任务上的第 1 落差悬殊；DNAChunker 的排名在 1–4 之间（最差 Cohn 第 4，2 个任务第 1），没有垫底任务——平均 rank 第一来自稳定，不是来自峰值。
- 能支持的结论：DNAChunker 在所有非物种控制任务上稳定排前列；在人类启动子任务上最好。
- 不能支持 / 混杂因素：作者把物种类任务（Mouse Enhancers、Human vs Worm、Coding vs Intergenomic 也涉及跨物种差异）的差距归因于"只训了人类基因组"，这是合理但未验证的解释——对照组 Generator 用了多种基因组。注意表中 Generator 的 Human Regulatory 标着 0.930 ± 0.000，标准差为零，多半是笔误。

### 4.3 Ablation studies

#### E3 — 对比 vanilla H-Net（Figure 2）

- 被检验贡献：两个架构改动——(1) 特殊 token 直通主网络；(2) cross-attention dechunking 替换 smoothing module。
- 对照变化：H-Net 用同样的 MLM 目标和同样的 HG38 数据训练（论文没说 H-Net 的单向编码器是否也换成了双向——如果没换，这场对比里混入了第三个变量，见下）。
- 关键结果：DNAChunker 在 NT benchmark 所有任务上更高，剪接位点任务差距最大。只有图、没有数字表。
- 证明了什么：整套架构改动相对 H-Net 原版是净收益；dechunking 的改动对需要碱基级精度的任务（剪接）增益最大，与 3.5 的机制分析一致。
- 未证明什么：两个改动捆绑在一起，**没有单独消融各自贡献**；H-Net 的编码器方向性改动（若发生）也没被隔离。所以"cross-attention dechunking 是关键"是合理推断，不是被实验隔离出的结论。

#### E4 — token 大小分布（Figure 1c、3、4）

- 被检验主张：分词复现生物学结构。
- 对照变化：BPE（DNABERT-2 的词表）对 DNAChunker 两阶段输出。
- 关键结果：H3C13/14/15 三个基因位点上，BPE 块大小均匀、无视注释；DNAChunker 在 phyloP 保守区和基因体用小块，SINE 重复区用大块。染色体 1/3/4/5/7（正文另说含 21、22，两处不一致）上按注释分组：启动子/外显子小块，内含子中块，重复区大块，重复区单块最大 320 bp。
- 证明了什么：分词与功能注释的相关性是真实的、跨染色体稳定的，不是个别位点的巧合。
- 未证明什么：相关非因果——没有实验显示"这个分词分布是下游性能提升的原因"。选 H3C13–15 三个位点有展示性选择的嫌疑（好在 Figure 4 的染色体级统计补上了随机性）。

#### E5 — 突变鲁棒性（Table 3）

- 被检验主张：分词对突变鲁棒。
- 对照变化：ClinVar 各抽 1000 个良性/致病的 SNV 和 InDel，比较参考序列与突变序列分词结果的相似度 S = 0.5·S_boundary + 0.5·S_content（S_boundary 是边界集合的 Jaccard 相似度，S_content 是 token 序列的编辑距离——**原文这里写着"edit distance"但高分表示更鲁棒，所以实际用的应是编辑距离的归一化相似度，表述有误**）。
- 关键结果：SNV 上全部 ≈0.999（BPE 甚至略高 0.9993 对 0.9987）；InDel 上 BPE 掉到 0.75，DNAChunker stage-1 0.85，stage-2 0.79（stage-2 更粗，边界扰动传播更远，符合预期）。
- 证明了什么：面对插入删除，DNAChunker 的边界比 BPE 稳定得多——BPE 的贪心合并连锁反应是真实可测的。
- 未证明什么：**没有和 k-mer 比**——引言里把 k-mer 的 shift 敏感当作头号靶子，但鲁棒性实验只对比了 BPE（k-mer 面对 1 bp 插入时边界 Jaccard 会趋近 0，比 BPE 输得还惨，测了只会更有利，没测是缺憾不是避险）。另外相似度指标是本文自造的，没有和下游性能建立联系——分词相似度高是否意味着表示相似度高，没有验证。

## 5. Limitation

### 5.1 作者明确报告

论文没有独立的 limitation 小节。正文里作者主动承认的只有一处：Genomic benchmark 上物种相关任务（Mouse Enhancers）表现一般，原因是模型只训了人类基因组，而 Generator 用了多种基因组。这是诚实的归因，但"只训人类"也是本文参数效率叙事的一部分，两者之间存在作者没点破的张力。

### 5.2 基于论文材料的解析推断

**5.2.1 缺最关键的一个消融：learnable 到底贡献了多少。**

论文的中心主张是"可学习分词"带来收益，但所有下游对比的参照物都是别的模型（Generator、NT、BPE 系），没有一个是"同样的 DNACHUNKER 架构 + 固定块大小（或 BPE 输入）"的对照。于是无法区分：下游收益来自"动态可学习边界"，还是来自"层次 U-Net 结构 + 双向 SSM + MLM 目标"这个总体架构。E3（对 H-Net）比较的是架构改动，E4/E5 展示的是分词行为漂亮——行为漂亮与"行为带来性能"之间隔着一条因果链，论文没有闭环。要补的实验：同架构固定块（取 α 压缩率的固定窗口池化）对照、以及 k-mer/BPE 输入进同一主网络的对照。这是这篇论文最值得被审稿人追问的地方，也是复现者最应该自己做的实验。

**5.2.2 "高效"没有实际测量。**

效率叙事（13% 参数、7.69× 少参数、主网络长度压缩）全部基于参数计数和结构论证。没有预训练 FLOPs、墙钟时间、显存占用、每任务微调耗时。而 DNAChunker 有 BiMamba 编码器（两遍扫描）、两个路由网络、两级 cross-attention 上采样——每 token 的常数成本高于普通 Transformer。压缩率的实际值取决于未公开的 α^(s)，主网络省下的算力可能部分被编码解码吃掉。宣称的"substantially reduced computational cost"目前是无法核实的。

**5.2.3 未公开的超参数伤复现。**

α^(0)、α^(1)、λ 三个值全文缺失——它们直接决定压缩率和两个损失的拉扯关系。ratio loss 权重大了，路由网络可能为了满足压缩率牺牲预测质量；小了，压缩率漂移。这是这篇论文复现路上的第一个坑。加上 3.6 列的正文/附录不一致（2048 vs 8192、pooling 两种说法、β2 异常），复现者需要自己猜若干处。

**5.2.4 微调的不稳定性迹象。**

Genomic benchmark 的微调 LR 落在搜索网格两端：8 个任务里 5 个用 5e-6（网格下界）、2 个用 5e-4（上界）、1 个用 1e-4 配 BS 128（上界）。最优值贴边通常意味着真实最优在网格外，或微调过程本身敏感。这与"注意力池化 + 15 epoch + 单卡"的微调协议叠加，提示 DNAChunker 的微调可能比论文呈现的更挑剔——复现者要有心理准备。

**5.2.5 两个数字对不上，指向审稿前的仓促。**

"10 out of 18"（正文）对 12+1（表 1 实况）；"14.2%"的口径（逐任务平均 vs 总量 +12.2%）未说明；Table 3 的 0.8492 ± 0.16 疑似漏了小数点；Table 2 的 ±0.000；Figure 4 的染色体列表两处不一致；附录的 131k 例子与 8192 上限矛盾。单独看都是小事，合起来是同一件事：数值检查这一轮没过完。读这篇论文时，凡关键结论（尤其 10/18 和 14.2%）都应该回到原始表格自己核一遍。

**5.2.6 机制的哪些部分信到什么程度。**

可以放心信的部分：动态 chunking 的机制本身（余弦边界 + ratio loss 反馈）是 H-Net 验证过的，本文的移植在结构上自洽；分词与功能注释的相关性是跨染色体统计，可信度高；InDel 鲁棒性优于 BPE 是直接测量。需要打折的部分：一切"分词导致下游收益"的因果叙事（5.2.1）；"cross-attention dechunking 是关键"的归因（捆绑消融）；"mask 保护机制的动机"（论文给的动机是防泛化问题，但该机制也同时改变预训练的块分布——mask 附近 15% 的位置被强制切成 singleton，预训练与下游的块结构其实并不完全一致，论文说"防止 mask 特异分词"，但它自己引入了一个系统性的块结构差异，只是方向可控。这个代价论文没有量化）。

最后回到更大的问题：这篇论文真正值得带走的东西不是某个 benchmark 数字，而是一个可迁移的原则——**当表示需要压缩、而信息密度在输入上不均匀时，把压缩边界交给任务损失去训练，压缩就会自动变成信息密度图。** DNA 是这个原则的极端案例（功能区与重复区的密度差可达数量级），但任何长尾信息密度的序列域（蛋白质、音频、轨迹、基因组的变异图谱）都适用同一招。H-Net 给了机制，本文证明了它在双向 MLM 下可行、并且压出的结构有独立于训练目标的生物学意义。下一个自然的问题是 5.2.1 的那个消融——如果它做出来是负的，这篇论文的价值会从"新方法"降级为"新分析"；如果做出来是正的，这条线值得所有序列建模的人跟进。
